## MH Wilds Quest Maker v1.3

**Quests**
- Create, edit and install custom event quests (needs REFramework + Permanent Event Quest)
- Star rating, monsters, Normal / Tempered / Arch-Tempered, rewards from all 773 items
- Monster health shown before you load in, with strength and player-count scaling
- Quest search by name, monster, ID or map

**Builds**
- Build editor with skill totals, set and group bonuses, build codes
- Build calculator: list skills in priority order and it maxes the first, then the next
- Lock pieces, ban pieces, must-have skills, "Room for more" suggestions
- New results layout: weapon, head to legs, talisman, with rarity colors and every slot
- Import your in-game loadouts and send builds to an empty loadout slot (save backed up first)
- Gear and decoration icons built into the app

**App**
- Themes with two adjustable colors
- Updates now install from inside the app (Updates tab), no more browser downloads

First install: Windows may show "Windows protected your PC". Click More info, then Run anyway. Later updates install themselves without it.
